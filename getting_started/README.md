## 🛠️ Setting Up Your Environment

### Quick Start (5 minutes)
```bash
# 1. Clone this repo
git clone https://github.com/manuel-reyes-ml/learning_journey.git
cd learning_journey

# 2. Create virtual environment
python3 -m venv .venv
source .venv/bin/activate  # Mac/Linux
# .venv\Scripts\activate   # Windows

# 3. Install dependencies
pip install -r requirements.txt

# 4. Verify setup
python getting-started/environment-verification.py
```

### Detailed Setup
See [SETUP_GUIDE.md](./SETUP_GUIDE.md) for comprehensive installation instructions including:
- Python 3.11+ installation
- VS Code configuration
- Jupyter Notebook setup
- Git/GitHub setup
- SQL tools installation
