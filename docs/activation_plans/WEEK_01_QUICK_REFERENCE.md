## 🚨 IF YOU FALL BEHIND

### Missed Morning Session:
```
Option 1: Shift to lunch break (1 hr minimum)
Option 2: Extended evening (add 30-60 min)
Option 3: Saturday makeup time

DON'T: Skip entirely, guilt spiral
DO: Make it up same day if possible
```

### Missed Evening Session:
```
Option 1: Wake 30 min earlier next day
Option 2: Add time to Saturday
Option 3: Sunday extended session

DON'T: Try to cram 4 hours the next day
DO: Catch up systematically
```

### Feeling Overwhelmed:
```
STOP: Pause, breathe, assess
REVIEW: What's actually required vs. nice-to-have?
PRIORITIZE: Code > courses > reading
SIMPLIFY: Do one thing well vs. many things poorly
ASK: Post in r/learnpython or Discord
```
